# 计算工具 · tools_v1 / tools_v2

> 2026-09-26。给 Agent 加入三个确定性计算工具，在 10 道工具任务上评测（LangGraph Agent，提示词 a3，最多 8 轮，护栏退回 1 次）。

## 新增

| 组件 | 说明 |
|---|---|
| `dataset/synthetic_policies_v1.json` | 6 张合成保单（全部虚构）：产品、基本保额、生效日、签收日、已交保费、可选责任、历史理赔次数 |
| `src/rules.py` | `policy_lookup`、`benefit_calc`、`date_calc`。6 条赔付规则，每条带出处条款和原文关键句 |
| `dataset/tool_tasks_v1.jsonl` | 10 道工具任务，标准答案**人工推算**（不是用计算工具生成的），推算过程写在 derivation 字段 |
| `tests/test_rules.py` | 规则的原文关键句必须真实出现在对应条款中；工具结果必须与人工推算一致 |
| `src/eval_tools.py` | 程序评分：金额或日期是否正确、必要工具是否调用成功、工具调用成功率 |

计算范围有意收窄：只算重疾、中症、轻症三个等级；现金价值在保单上载明、条款里没有，重疾“三者取大”只比较基本保额和已交保费，并在结果中说明。

问答评测仍然只用 3 个检索工具（`--toolset qa`），计算工具只在工具任务上启用（`full`），之前的问答结果和缓存不受影响（回归检查 0 次新调用）。

## 任务设计

| 题 | 考点 |
|---|---|
| t01、t04、t06 | 正常给付：查保单 → 判断等级 → 计算 |
| t02、t09 | 可选责任未投保 → 不赔 |
| t03 | 泰康 90 日等待期内确诊 → 退还已交保费 |
| **t05** | **陷阱**：国寿 180 日内确诊轻度疾病 → 合同终止，按已交保费给付，而不是按 20% |
| t07 | 日期：“自次日起六十日”的宽限期最后一天 |
| t08 | 意外不受观察期限制 |
| t10 | 已达给付次数上限 |

## 结果

| | tools_v1 | tools_v2（修正检查器后） |
|---|---|---|
| 结果正确 | **10/10** | **10/10** |
| 必要工具都调用成功 | 10/10 | 10/10 |
| 工具调用成功率 | 95.6%（65/68） | 95.2%（59/62） |
| 护栏退回 | 7 次 | **1 次** |
| 输入 token | 21.6 万 | 17.1 万（−21%） |

### 发现一：检查器在工具任务上大量误报（已修）

tools_v1 中 7/10 题被护栏退回，全是误报：
- 计算结果是 JSON（`"amount": 0`、`"claims": {"轻症": 2}`），数字不带单位，答案里的“0元”“2次”匹配不上；
- 日期被拆成数字事实：“2026年5月10日”里的“10日”被当成天数。

模型每次都按退回意见改了，所以结果仍然正确，但多花了调用。修正方法：抽取数字事实前先去掉日期；计算工具的结果只比较数值、不比较单位。修正后问答任务的检查结果不变，23 个测试通过。

剩余 1 次误报（t07“最后一日”被当成“1日”）**有意不再修**：这三轮修正都是看着这 10 道任务的失败做的，继续调会变成给这批题量身定做。

### 发现二：3 次工具调用失败，都被程序校验拦住

- t04（2 次）：模型把内部的工具调用格式漏进了参数字符串（`</answer><parameter name="answerable">true`），导致缺少必填参数。
- t09：`read_clause` 的条款号写成“第九条 保险责任”（带了标题）。

错误信息返回给模型后都自行改正，没有一题因此失败。

### 发现三：陷阱题都过了

- t05：模型先用 `date_calc` 算出 180 日观察期到 2026-11-05，再由 `benefit_calc` 给出“合同终止，按已交保费 6200 元给付”。
- t07：模型自己把“自次日起”换算成从 5 月 11 日起算，得出 2027-07-09。

## 结论（AI 起草，待学习者确认）

1. **把规则写成确定性工具，金额和日期就不再依赖模型心算**，10/10 正确；模型负责理解问题、选工具、判断疾病等级。
2. **规则的正确性靠测试兜底**：规则由 AI 从条款编码，测试逐条核对原文关键句，并与人工推算的答案对比。
3. **护栏要按内容类型区分**：同一套数字检查用在条款片段上很准，用在 JSON 工具结果上就大量误报。

## 局限

- 10 道题都是我（AI）设计的，覆盖面有限；没有涉及需要先检索定义才能判断等级的题（如“甲状腺癌Ⅰ期”这类要先查定义的）。
- 规则只覆盖 6 种“产品 × 等级”组合；身故、豁免、关爱金、特定疾病额外给付都没算。
- 每个配置只跑了一次。
