## 目录

| 目录 | 用途 |
|---|---|
| `src/` | 由你逐步编写代码，暂不预设核心模块 |
| `data/` | 本地原始材料和派生数据；除目录占位文件外均不纳入 Git |
| `dataset/` | 后续由你建立来源清单和评测题；提交前检查内容与公开边界 |
| `reports/` | 后续由你记录实验结果、失败分析和结论 |

不使用真实客户保单、健康资料或账户信息。公开可访问的材料也不默认允许重新分发；原始材料及大段解析文本先只存本地 `data/`。

## 第一个学习任务

暂时只做这一小步，不要求先写代码：

1. 自己选择并阅读一份官方公开保险条款，将文件保存在 `data/`。
2. 记录来源 URL、产品名称和能够确认的版本信息；不清楚的字段保留为未知。
3. 亲手写 3 个问题，为每题找到页码或条款编号，并写出答案要点。

完成后，把问题和证据交给 AI 检查。AI 不提前生成标准答案。
